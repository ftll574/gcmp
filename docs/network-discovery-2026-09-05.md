## 完成內容

探索器現在預設顯示所選兌換方案的所有合資格營運航空，以目前行程終點查找下一段。
同一目的地可有多家航空，各自有新增按鈕，選定的營運航空原樣寫入行程。
加入航段後，起點跟隨新終點，航空／搜尋篩選重設；手動改序或分享導覽也不會沿用另一個終點的起點覆寫。
找不到終點資料時顯示未收錄，不會偷偷跳回 TPE 或其他有資料的樞紐。

支援目的地機場代碼、英文城市／國家及既有繁中城市別名搜尋，保留洲／區域／國家分組。
其他起點收在瀏覽區；不能接到目前終點的選項保持不可加入，並提示所需起點。
來源與日期在各航空選項下可展開；資料未載入有明確提示，既有班表及手動輸入仍可用。

不抄用舊公告的週班次、不把新座艙投放日當航線啟航日、不把票價頁的任意轉機組合當直飛。
Lufthansa 頁面的 UA 聯營航班按實際 UA 營運建檔；FRA/MUC 頁面中的 ZMU 鐵路、XX 與 4Y 營運項未混入 LH。

## 航線、班表與座位分離

新 schema 沒有 `daysOfWeek` 或獎勵座位欄位，未知欄位會驗證失敗。
來源引用、日期格式、重複機場對、重複來源、起訖相同與機場目錄完整性都有檢查。

顯示四種日期資訊：班表涵蓋此日、營運星期不符、只有航線紀錄而班表待查、不在觀測有效期間。
新航線紀錄不會傳入日期選擇器充當班表，因此 CX 等僅有航線證據的日期不會被虛構的星期限制鎖住。
明確有效的停飛／network-gap 紀錄優先於一般航線觀測；其他航空的服務不因同一目的地被一起刪除。
所有選項都不代表已查到可兌換座位，整張票的規則及價格仍由既有引擎判定。
